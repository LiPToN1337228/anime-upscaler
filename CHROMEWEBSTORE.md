## 2. Detailed Description

**Anime UpScaler PRO** — мощное расширение для браузеров Chrome и Brave, выполняющее высококачественный нейросетевой апскейл, очистку от артефактов компрессии и восстановление контуров аниме в реальном времени прямо в плеере.

### ✨ Ключевые возможности:
- **Настоящие нейросетевые веса Anime4K:** Высокоточная обработка WebGL2 в формате полутонов высокой точности (RGBA16F).
- **Supreme Godmode (50-Pass UL):** Флагманский ультра-режим на 50 сверточных проходов (RestoreUL + UpscaleUL) для мощных дискретных видеокарт.
- **Режим 4 (AnimeSR):** Полная поддержка популярной 4-проходной цепочки `Restore + Upscale + Restore + Upscale`.
- **Режим 4 Turbo:** Интеллектуальный 3-проходный алгоритм с 3-кратным снижением нагрузки на видеокарту и нулевым риском перегрева.
- **HQ Кинематографичный:** Задействует продвинутые нейросети M-класса для глубокого очищения линий и насыщенных текстур при стабильных 60 FPS.
- **Ultra Master:** Максимальная детализация L-класса для мощных видеокарт с большим объемом видеопамяти.
- **AMD FidelityFX CAS:** Адаптивное локальное повышение резкости контуров без белых ореолов.
- **4K Снимок кадра (Обои):** Сохранение текущего кадра в оригинальном 4K разрешении в один клик.
- **Сравнение A/B (Split-Screen):** Интерактивный ползунок разделения экрана для сравнения оригинального видео и апскейла в реальном времени.
- **Умный авто-баланс (Zero-Idle):** Динамический контроль кадрового бюджета (EMA ms) и автоматическая остановка рендера на паузе для сохранения тишины кулеров.
- **Интерактивный HUD & Сворачивание:** Легкий оверлей со статусом, разрешением, FPS и автоскрытием при просмотре.

### ⌨ Горячие клавиши:
- `Alt + Shift + Q`: Включение / Выключение
- `Alt + Shift + S`: Режим сравнения (A/B Split-Screen)
- `Alt + Shift + F`: Показать / Скрыть FPS и оверлей HUD
- `Alt + Shift + 1` / `Alt + Shift + 2`: Переключение режимов мощности
